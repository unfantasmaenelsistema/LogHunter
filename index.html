              Indicadores en Logs Web (HTTP)
            

            
    
              
  • HTTP 403 / 404: Escaneo de rutas (/.env, /.git) o bloqueo WAF.
    • 
              
  • HTTP 200 + SQLi: Payloads UNION SELECT con respuesta exitosa y bytes elevados.
    • 
              
  • Doble URL Encoding: Patrones %252f..%252f para evadir filtros Path Traversal.
    • 
              
  • POST + RCE: Ejecución en rutas de subida (/uploads/*.php) o parámetros cmd=.
